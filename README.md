# Браузер для «Пульса»

Настоящий Chrome для агентов — для веб-задач, которые не решить запросом к серверу:

- **найти и купить** — книгу, велосипед на Ozon — и оформить доставку на нужный адрес;
- **документы из открытой базы**, где нет API: поиск через формы, скачивание по кнопке;
- **сервисы со входом владельца**: владелец входит сам в живом просмотре, агент работает в его сессии.

## Как устроено

- **Сессия** — именованный профиль Chrome (вход в сайты, куки), свой прокси (российский для российских магазинов),
  свой режим: `read-only` — агент только смотрит, `write` — кликает и вводит. Режим `write` включает владелец.
- **Агент видит страницу** через `snapshot`: видимые кнопки, ссылки и поля со ссылками `e1, e2…` и текст страницы.
  `click`, `type`, `select`, `download` принимают `--ref`. Клик — настоящими событиями мыши, ввод — `insertText`
  (его понимают React-формы), файлы — с куками и прокси сессии.
- **Оплата и оформление заказа — только с подтверждением владельца.** На странице оплаты (адреса из настройки
  `confirm_patterns`) действие агента превращается в запрос: что он хочет нажать, на какой странице, со скриншотом.
  Владелец решает на странице плагина «Разрешить один раз» или «Отклонить». Разрешение — на одно это действие; сам
  агент подтвердить не может: Пульс сообщает плагину, кто зовёт (`X-Pulse-Caller`, контракт 1.7), и подтверждение
  принимается только от владельца.
- **Живой просмотр** на странице плагина: кадры Chrome, клики, колесо, клавиши, вставка — для входа в аккаунты и
  проверок «вы не робот».
- Chrome без дела закрывается (`idle_minutes`), вход в сайты остаётся в профиле. Скриншоты шагов — `@browser/<сессия>/`
  (последние `keep_screenshots`), журнал действий — `@browser/<сессия>/runs/`.

## Команды агентов

```bash
pulse browser sessions | session create|update|delete
pulse browser open --session S --url URL [--wait_idle true]
pulse browser snapshot --session S [--format page|a11y|html|both]
pulse browser click|type|select --session S --ref e12 [--confirm c…]
pulse browser press --session S --key Enter
pulse browser download --session S --ref e42 | --url URL
pulse browser tabs | tab new|select|close | wait | view | close
pulse browser pending [--id c…]
pulse browser check
```

Справка — `pulse browser --help`, правила для агентов — `skills/browser.md`.

## Ограничения

- Сервер Пульса за рубежом не достаёт до части российских сайтов (Ozon) — сессии нужен российский прокси.
- Сайты с защитой от ботов (DDoS-Guard, капчи) проверяют и такой Chrome: проверку проходит владелец в живом
  просмотре; не проходится — другой прокси.
- Нужен Docker: образ с Chromium собирается при установке.

## Разработка

```bash
pip install -r backend/requirements-dev.txt
pulse-plugin check
cd backend && python -m pytest          # без Chrome
```

Нужен Пульс с контрактом плагинов 1.7. История: `docs/ТЗ v0.1.md`, `docs/ТЗ v0.2.md`, аудит и 0.3 — `CHANGELOG.md`.
