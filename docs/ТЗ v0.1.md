# ТЗ — плагин browser v0.1

## Use-cases
1. Владелец создаёт сессию, открывает сайт на странице плагина, логинится сам.
2. Агент делает поиск / читает страницу (`snapshot`) в этой сессии.
3. Агент заполняет форму в mode=write.
4. Покупка / checkout — только после confirm владельца.

## Модель сессий
- Имя → persistent user-data-dir + proxy + mode + allowlist.
- Один writer (lock); snapshot без блокировки надолго.
- Аудит: `runs/<session>/*.json` + скрины до/после мутаций.

## CLI v0.1
sessions, session create/update/delete, open, snapshot, click, type, press, select,
tabs, close, view, confirm, pending, check.

## UI
`/p/browser/main` — список сессий, screenshot overlay (клик/ввод), pending confirms.

## Не в v0.1 (v0.2+)
Live multi-tab switcher, networkidle waits, screencast stream, noVNC.
